Projects

Grich

Model (Grich-S) Test set (HamaKet)

Armenian punctuation restoration model

  • Trained a compact 47.8M-parameter encoder that tags every gap between two letters with an exact edit; a deterministic decoder writes the text and never changes a letter.
  • Runs on-device: 49.8 MB as an 8-bit ONNX file, 23 ms for a 30-word sentence on a Pixel 7 inside an Android keyboard.
  • Ranked #1 on the public ArmBench punctuation leaderboard (0.793), ahead of GPT-5.2 Pro (0.784) and Gemini 3 Pro (0.739).
  • Built HamaKet, a 1,144-sentence test set from the two Eastern Armenian Universal Dependencies treebanks, scored only where human editors, Claude and Gemini agree; 322 sentences were reviewed by a native speaker.
  • On HamaKet, Grich-S scores F1 0.926: ahead of Claude Sonnet 5.5, Claude Haiku 5.5 and every public punctuation model, and behind only Claude Opus 5.5.
  • Analysed errors by syntactic construction using Universal Dependencies trees; showed that clean consensus labels add +0.026 F1 with minutes of fine-tuning.

Formatting ASR transcripts with copy-augmented encoder-decoders

MSc thesis, published at IEEE CODASSCA 2026. Paper (PDF)

  • Added a position-aware pointer-generator gate (PG-pos) to flan-T5-XL fine-tuned with LoRA to restore punctuation, casing and formatting in raw ASR output.
  • 57.6% exact match and 0.0201 CER on a 3,965-sample benchmark.

RegexForge

Code Live demo

Fine-tuning a 1.5B model to write regular expressions

  • Two-stage training on a single 8 GB laptop GPU: QLoRA supervised fine-tuning, then GRPO with a reward computed by running the generated regex against held-out test strings. No reward model and no LLM judge.
  • 71.4% strict functional accuracy in-domain, against 2.3% for the few-shot base model and 21.2% for Claude Sonnet 4.5 on the same prompt and verifier. Out-of-domain the result reverses (27.5% vs 67.4%), and both are reported.

Semantic Change Radar

Code Recorded examples

Finds meaning changes between two versions of a document

  • Aligns passages with MiniLM embeddings and lexical similarity, then uses bidirectional NLI with numeric, condition and actor guards to separate paraphrases from material edits.
  • Runs on CPU with two small ONNX models, no API key or GPU, and shows the source evidence beside every finding.
